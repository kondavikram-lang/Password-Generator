## Brand & Style

This design system embodies a fortified, precision-engineered cybersecurity aesthetic. It balances clinical digital defense with high-fidelity consumer elegance. 

- **Personality:** Authoritative, impenetrable, hyper-modern, and fluid. It conveys total cryptographic certainty without feeling academic or sterile.
- **Target Audience:** Privacy-conscious digital natives, security engineers, and everyday mobile users demanding zero-compromise credential protection.
- **Emotional Response:** Invulnerability, rapid mastery, tactile delight, and uncompromising trust.
- **Design Movement:** Cyber-Glass Minimalism. The design synthesizes deep midnight surfaces, luminous indigo/violet signal paths, micro-glows, and precise translucent borders to simulate a hardened, illuminated security enclave.

## Colors

The palette is engineered around subterranean darks and electric luminescence, establishing stark contrast ratios (minimum 7:1 for text, 3:1 for structural UI elements).

- **Core Luminescence (Primary & Secondary):** `#6366F1` (Vibrant Indigo) acts as the interactive anchor, paired with `#818CF8` (Electric Violet-Indigo) for high-visibility highlights, active glows, and focused strokes. Deep anchor `#4F46E5` is reserved for pressed button states and active gradient underlays.
- **Security Semantics:**
  - **Secure / Entropic Peak (Success):** `#10B981` (Shield Emerald) signifies bulletproof entropy, validated vaults, and verified tokens.
  - **Vulnerability Alert (Warning):** `#F59E0B` (Amber Caution) indicates moderate entropy, stale credentials, or unencrypted syncs.
  - **Breach / Critical (Danger):** `#F43F5E` (Rose Hazard) communicates compromised passwords, leaked records, and destructive actions.
- **Surfaces & Neutral Layering:**
  - **Base Canvas:** `#0B0F19` (Void Midnight) provides deep chromatic blackness.
  - **Surface Layer 1:** `#111827` (Deep Obsidian) for primary module backing.
  - **Surface Layer 2:** `#1E1B4B` (Tinctured Indigo Slate) for elevated cards, active toggles, and modal headers.
- **Border Gradients:** Translucent stroke matrices blend from `rgba(99, 102, 241, 0.35)` to `rgba(255, 255, 255, 0.05)`, defining sharp boundaries against absolute dark backgrounds.

## Typography

The typography architecture uses a bi-font structural pairing to contrast high-level narrative authority with raw cryptographic clarity.

- **Primary Interface (Plus Jakarta Sans):** Handles headlines, titles, and continuous body text. Rounded geometries soften structural technicality while maintaining crisp legibility on high-DPI OLED screens.
- **Cryptographic & Code Layer (JetBrains Mono):** Mandated for password output fields, hash strings, security score badges, entropy metrics, and micro-labels. Character distinction (e.g., `0` vs `O`, `l` vs `1`) is chemically clear to eliminate input mistakes.
- **Letter Spacing Rhythms:** Headlines employ tight negative tracking (`-0.01em` to `-0.03em`) for a condensed, engineered finish, whereas code and status tokens leverage open, tracked caps (`+0.06em` to `+0.08em`) to maximize scannability.

## Layout & Spacing

The layout model is mobile-first, using a 4-column fluid layout on phone displays that expands to an 8-column layout on foldable devices and tablets (breakpoint: 640px).

- **Vertical Rhythm:** Fixed to an uncompromising 4px base coordinate grid. Structural modules align on multiples of 8px (`space-sm`, `space-md`, `space-lg`).
- **Canvas Boundaries:** Screen horizontal edge padding is anchored at `1.25rem` (20px) on mobile viewports, maintaining a protective gutter around interactive generator modules, and shifts to `2rem` on viewports above 640px.
- **Viewport Safe-Areas:** Top safe zone accommodates status indicators with an integrated 12px dynamic padding; bottom actions sit 16px above the home indicator bar with high-opacity backdrop-filtered grounding.

## Elevation & Depth

Visual hierarchy uses physical glass stratification, luminous light dispersion, and tonal containment rather than standard drop shadows.

- **Layer 0 (Canvas):** `#0B0F19` with a subtle radial gradient wash (`radial-gradient(ellipse at 50% -20%, #1E1B4B 0%, transparent 60%)`) to create environmental depth.
- **Layer 1 (Recessed Containers & Tracks):** `#070A10` with inset shadows (`inset 0 2px 4px rgba(0, 0, 0, 0.6)`) and a `1px` stroke of `rgba(255, 255, 255, 0.04)`. Used for password display fields, inactive sliders, and empty vault states.
- **Layer 2 (Floating Glass Panels):** `rgba(17, 24, 39, 0.75)` with a `backdrop-filter: blur(20px)` and dual borders: top/left edge tinted at `rgba(129, 140, 248, 0.25)` falling away to bottom/right edge at `rgba(255, 255, 255, 0.03)`.
- **Layer 3 (Modal / Tactical Elevation):** `rgba(30, 27, 75, 0.85)` with `backdrop-filter: blur(32px)`, combined with an ambient peripheral glow: `0 12px 32px -8px rgba(99, 102, 241, 0.35)`.
- **Luminescence / Active State:** Interactive triggers and active entropy states emit focused light cones (`box-shadow: 0 0 20px rgba(99, 102, 241, 0.45)` for primary interactions; `box-shadow: 0 0 20px rgba(16, 185, 129, 0.45)` for maximum entropy).

## Shapes

The geometry pairs structural solidity with organic curves.

- **Base Radius (0.5rem / 8px):** Applied to compact inputs, micro-tags, segmented controls, and copy action buttons.
- **Large Container Radius (1rem / 16px - `rounded-lg`):** Assigned to interactive feature toggles, password length sliders, and security audit list elements.
- **Prominent Card Radius (1.5rem / 24px - `rounded-xl`):** Assigned to the central Password Generator display card, biometric confirmation dialogues, and bottom action sheets.
- **Full Pill (`9999px`):** Reserved exclusively for status indicator tags (e.g., "AES-256", "HIGH ENTROPY") and floating action triggers.

## Components

### Password Generator Canvas (Hero Card)
- **Structure:** Floating Layer 2 card, `rounded-xl` (24px), framed by an electric indigo-to-transparent glassmorphic border (`1px`).
- **Display Output:** Recessed inner well with monospaced `code-display-mobile` typography. Character groups alternate color: alphabetic characters in `#FFFFFF`, numerals in `#818CF8`, and symbols in `#10B981` for quick parsing.
- **Integrated Action:** Quick-copy floating button positioned within the display edge, triggering a transient Shield Emerald pulse on tap.

### Buttons & Quick Actions
- **Primary CTA ("Generate", "Save Vault"):** Full-width, `rounded-lg` (16px), background: linear gradient from `#6366F1` to `#4F46E5`. Features an active violet ambient glow (`0 8px 24px rgba(99, 102, 241, 0.45)`). Pressed state shifts background to `#4F46E5` with `transform: scale(0.98)`.
- **Secondary / Tactical Buttons:** Translucent glass fill `rgba(30, 27, 75, 0.6)`, `1px` border of `rgba(129, 140, 248, 0.3)`, text in `#818CF8`.
- **Destructive Buttons:** Inset crimson surface `rgba(244, 63, 94, 0.1)`, border in `rgba(244, 63, 94, 0.3)`, text `#F43F5E`.

### Entropy Meter (Strength Gauge)
- **Track & Fill:** Recessed `8px` rounded-full track with track color `#111827`. Dynamic fill transitions smoothly via CSS transition across 4 segmented bars:
  - Weak: 1 bar (`#F43F5E`).
  - Moderate: 2 bars (`#F59E0B`).
  - Strong: 3 bars (`#6366F1`).
  - Impenetrable: 4 bars (`#10B981`) accompanied by a soft emerald edge flare.

### Sliders (Length & Parameter Controls)
- **Track:** 6px thickness, background `#1E1B4B`, active track `#6366F1`.
- **Thumb:** 24px circular disc with an outer glow, solid `#FFFFFF` core, and a centered `#4F46E5` indicator ring.

### Toggles & Rule Switches (Symbols, Uppercase, Numbers, Ambiguous)
- **Card-Style Item:** Stacked lists inside Layer 1 container (`rounded-lg`). Each rule item features an icon badge, title in `body-md` bold, and an iOS-style rounded-full switch (`rgba(255, 255, 255, 0.1)` inactive; `#6366F1` active).

### Feedback Badges & Chips
- **Format:** Micro-pills using `label-sm` (`JetBrains Mono`). 
- **Variants:**
  - *Standard:* Background `rgba(99, 102, 241, 0.12)`, border `rgba(99, 102, 241, 0.25)`, text `#818CF8`.
  - *Secure:* Background `rgba(16, 185, 129, 0.12)`, border `rgba(16, 185, 129, 0.25)`, text `#10B981`.
  - *Breached:* Background `rgba(244, 63, 94, 0.12)`, border `rgba(244, 63, 94, 0.25)`, text `#F43F5E`.
